# 合成业务评测夹具

这些文件用于 `tools/business_eval.py` 的 B01–B12 开发试跑，均为自建非敏感测试文本。它们不是实际设备说明书、真实病历、已开展试验或临床知识库。

- `cases.json`：12 个场景、17 轮，包含必需工具/来源、禁止动作、关键词冒烟规则。不是逐句语义裁判。
- `corpus.json`：4 份合成资料，9 个完整章节。`approved=true` 和 `approved_by=technical-synthetic-eval-2026-10-11` 仅表示隔离技术评测准入，不是独立产品或临床审批。
- `frozen.sha256.json`：用例与语料 SHA-256。加载前校验，不允许随运行结果悄悄修改。
- `gold-review-log.json`：最初评分/夹具修订原因及原始输入位置。修订后重新跑基线，再修改产品代码。
- `local_rollback.json`：原集成用例 E08 的独立本地回滚来源，用于来源校验，不混入业务知识库。

业务记录由 `SyntheticBackend` 在进程内有限提供，唯一测试身份为 `900001`。未种子的端点/记录直接拒绝，不回退到实际后端。未知单位适用于所有可访问记录；占位零和实测零不同。就诊夹具有明确医嘱、空诊断列表，**未提供处方字段**；这不意味着不存在处方。

本目录自建资料以 CC0-1.0 提供用于技术测试。没有引用私有 PDF 或患者内容。临床审批固定为 false，人工 Gold 审阅为 NOT_ASSESSED。原有远程演示仍禁止患者绑定；不要用本夹具绕过该 gate。

运行与实际局限见[评测结果](../../docs/business-rag-eval-results.md)。所有模型试跑是已打开开发集上的迭代；三次重复不是三个独立盲测集。

后续核对发现，本版就诊与康复响应为简化结构，未与 AI_WebApi 当前 DTO 完整对齐；不能将其成绩当作实际接口契约覆盖率。下一版将另行冻结契约对齐夹具并重跑基线，见[改进方案](../../docs/business-rag-improvement-plan.md)，本版 hash 和历史输入不修改。
